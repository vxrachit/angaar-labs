# Frontend Design System

## Brand Direction

The Angaar Labs follows an "angaari" visual identity.

The intended feeling is:

- Fiery
- Bold
- Premium
- High-energy
- Confident
- Cinematic

## Buttons

### Primary

Ember-filled CTA.

### Secondary

Outline or ghost CTA.

### Text

Minimal text link.

Buttons should have hover, active, focus, and touch-friendly states.

---

## Cards

Cards should follow the same visual language across Services and Work.

Possible interactions:

- Lift
- Scale
- Image movement
- Accent transition
- Border transition

---

## Motion Principles

1. Motion should have a purpose.
2. Avoid animating everything.
3. Prefer transform and opacity.
4. Keep transitions smooth.
5. Avoid excessive glow.
6. Respect `prefers-reduced-motion`.
7. Maintain performance on mobile.

---

## Responsive System

The design must work from 360px to desktop.

Responsive considerations include:

- Typography scaling
- Grid changes
- Navigation changes
- Section padding
- Image sizing
- CTA stacking
- 3D scaling
- Animation reduction

---

## Visual Principles

### Hierarchy

Every section should have a clear focal point.

### Consistency

The same design language should appear across the entire site.

### Whitespace

Use generous spacing rather than filling every available area.

### Contrast

Visual style should never compromise readability.

### Originality

The website should not look like a copied template or default component-library demo.
