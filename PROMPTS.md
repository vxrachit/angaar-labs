## Prompt 01 — Project Direction

### Prompt

We are building The Angaar Labs official website for a full-stack vibe-coding examination.

The website is a premium UI-first web-development studio website.

The main evaluation focus is visual design, motion, responsiveness, component architecture, and overall user experience.

Use React/TypeScript and create an original design rather than cloning an existing website.

### Result

Established the overall frontend direction and architecture.
